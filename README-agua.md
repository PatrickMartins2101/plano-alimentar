# Controle de Água — Plano Alimentar v2

Este módulo adiciona ao aplicativo:

- Meta diária de água configurável.
- Registro rápido de 250 ml, 500 ml, 750 ml e 1 litro.
- Botão para adicionar ou retirar 250 ml.
- Barra visual de progresso.
- Percentual da meta atingido.
- Quantidade restante.
- Persistência no `localStorage`.
- Dados separados por dia.
- Botão para zerar o registro do dia.

## Como adicionar ao GitHub

1. Envie `agua.js` para a raiz da branch `v2-progressao`.
2. Abra o `index.html`.
3. Antes de `</body>`, adicione:

```html
<script src="agua.js"></script>
```

4. Faça o commit.
5. Aguarde o GitHub Pages atualizar.

O módulo foi feito para funcionar sem alterar a estrutura atual do plano alimentar.
